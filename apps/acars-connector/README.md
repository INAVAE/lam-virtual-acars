# LAM ACARS Connector

Aplicación de Windows (.NET 8, WPF, SDK de SimConnect de MSFS 2024) que lee la telemetría del simulador y la envía a LAM Virtual ACARS.

Estado: **pendiente, Fase 4.** El contrato con la plataforma está en `docs/integrations/acars-api.md` y la estrategia de telemetría en `docs/decisions/0004-telemetria-en-lotes.md`.
